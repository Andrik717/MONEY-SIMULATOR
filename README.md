# MONEY SIMULATOR

Исходный код Roblox-проекта, управляемый через Rojo.

## Структура

- `src/server` — серверные Script.
- `src/shared` — общие ModuleScript и RemoteEvent.
- `src/client` — клиентские LocalScript.
- `default.project.json` — конфигурация Rojo.

## Запуск

1. Откройте папку репозитория в VS Code.
2. Убедитесь, что установлен Rojo CLI 7.7.1.
3. В терминале VS Code выполните:

   `C:\Rojo\rojo.exe serve`

4. В Roblox Studio подключитесь к локальному Rojo-серверу через плагин Rojo.

Перед подключением к основной игре сделайте резервную копию place-файла.
